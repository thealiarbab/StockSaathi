### Key root causes found (so nobody re-breaks them)
- **Chat order**: `logChatTurn` wrote question+reply rows in parallel with
  server `now()`; reply often landed first; boot rebuild sorted by
  created_at; the flat rebuild then overwrote the cloud doc. Fix:
  `js/features/chatOrder.js` (nextTs / byTurn / repairTurnOrder — repair
  NEVER changes ts, merges key on role:ts), rows carry `payload.ts`,
  sequential inserts, `fromLog` sessions never beat chat_threads,
  `keepRicherLocal` in sync.js rebuild.
- **Chat jitter**: `scroll-behavior: smooth` + scrollTop every 18 ms.
  `stickBottom`/`paintList` follow only at bottom; ResizeObserver re-sticks
  when cards grow.
- **Transfers counted as profit**: completed 20 Aug transfers (saim got
  ₹2 lakh from ananyaa08 + cmonnnnn) stayed in balances after the feature
  was removed 16 Oct. `returnSummary`: capital = cash + reserved + Σbuys −
  Σsells; profit = realised + paper. gpta has ₹33,333 unexplained — treated
  as capital. No balances were changed.
- **Invented prices**: `_bestKnownPxPaise` fell back to `getPriceAt` walk.
  Now real quote (stale ok) → MF NAV → else valued at cost ("at cost").
- **Market order latency** (5.7 s median vs 0.47 s AMO): two
  `/api/live-quote?nocache=1` Yahoo fetches + fake 400–900 ms delay. Now
  page quote if <20 s old; `_quote_not_live_reason` enforces 60 s for
  users (auth.uid() not null), 5 min for the matcher; client retries once on
  "more than a minute old" with same idempotency key.
- **Unlisted stocks**: build-universe dropped rows; 7NR, ADCINDIA, BMW, KEL
  held. Now carried 1 year as `listed:false`; loader keeps them in
  `_unlistedBySymbol` (lookup only). Drop-check counts live rows BEFORE

  in pieces. `create_edge_function_secret` needs the owner to type values in
  the dashboard → store secrets in Vault and read them via a service-role
  RPC instead. Test risky SQL inside `do $$ … raise exception 'RESULT …' $$`
